# Simon Latham Music Archive

A standalone public archive of Simon Latham's progressive house and trance history, separated from the TRAX digital audio workstation.

## Browse locally

```bash
npm install
npm run dev
```

## Browser pages

- [Article archive](./)
- [DJ Support Database](./dj-support.html) — searchable table with Excel, CSV, and JSON downloads

## Contents

- 49 canonical Markdown articles in `articles/`
- Searchable browser interface
- Full combined AI-readable archive: `progressive-house-kb-full.md`
- MCP server in `mcp-server/`

The browser dataset includes every canonical article. Biographical material and first-person music-career memories are published with Simon Latham's approval.
